# Agent registry

| ID | Agent | Owns | Output |
|---|---|---|---|
| TM-01 | Transaction Monitor | Trading, lending, sanctions and MNPI typologies | Findings and transaction context |
| CS-01 | Communication Scanner | Channel, retention and misleading-communication signals | Findings and evidence warnings |
| RU-01 | Regulatory Update Tracker | Jurisdiction and rule-version context | Regulatory context envelope |
| RG-01 | Report Generator | Risk aggregation, remediation and escalation | Compliance report |

Agents cannot approve their own findings, release sanctions holds, or delete audit records.
